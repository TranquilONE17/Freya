                            Conversations

                            Each time Freya runs is one conversation. She starts each new one knowing the summaries of the last few.

                                Cloud models Freya may use

                                Freya answers you herself, on this computer. With a box ticked she may hand part of a task to that company's model, through your own subscription. With every box clear, nothing is sent anywhere. Ticking a box unlocks that provider: it is allowed, and given a weekly allowance you can change. Clearing the box locks it again.

                                What may leave this computer

                                For each kind of material: allowed, ask you first, or never. Nothing you answer in a prompt can send a kind set to never.

                                How good a model must be

                                The share of test tasks a model must have passed, for a kind of work, before Freya gives it work of each value. Low cannot ask more than normal, nor normal more than high.

                                Corrections to screening

                                Before anything is sent, it is compared with what Freya has saved about you, and held if it matches. Here you correct that. "Not private" stops a phrase or one memory from holding a brief. "Always private" always holds it, and wins. Use a memory's number from the Memory tab.
